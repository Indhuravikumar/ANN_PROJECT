# Moon Dataset Classification Using ANN

## Project Overview
This project uses an Artificial Neural Network (ANN) to classify data points into two classes using the Moon dataset generated by Scikit-learn. The model learns patterns from noisy data and predicts the class of unseen data points.

## Technologies Used
- Python
- Scikit-learn
- NumPy
- Artificial Neural Network (ANN)
- StandardScaler

## Dataset
The dataset is generated using Scikit-learn's `make_moons()` function.

- Total Samples: 1,000
- Number of Classes: 2
- Noise Level: 0.7
- Training Data: 80%
- Testing Data: 20%
- Random State: 42

## Model Architecture
The project uses an `MLPClassifier`, which is a feedforward neural network.

- Input Layer: 2 input features
- Hidden Layer: 8 neurons
- Activation Function: ReLU
- Output Layer: 2 classes
- Optimizer: Adam
- Learning Rate: 0.01
- Batch Size: 32
- Maximum Iterations: 50

## Data Preprocessing
1. Generate the Moon dataset.
2. Split the dataset into training and testing sets.
3. Standardize the input features using `StandardScaler`.
4. Train the neural network using the training data.

## Installation


## How to Run

1. Save the Python code in a file named `ann.py`.
2. Open the terminal in the project folder.
3. Run the following command:

```bash
python ann.py
```

## Model Evaluation
The model is evaluated using:

- **Accuracy:** Measures the proportion of correct predictions.
- **Classification Report:** Displays precision, recall, F1-score, and support for each class.

Example output:

```text

Classification Report:
```

The actual results depend on the training process.
